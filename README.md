# FOCUS BLOG ASSISTANT v2.0

## 가장 쉬운 실행
`index.html` 파일을 더블클릭하면 브라우저에서 바로 실행됩니다. 서버, Cloudflare, npm, API 키가 필요 없습니다.

## 가장 쉬운 온라인 배포: GitHub Pages
1. GitHub에서 새 공개 저장소를 만듭니다.
2. 이 ZIP의 `index.html`을 저장소 최상위에 업로드합니다.
3. 저장소 Settings → Pages로 이동합니다.
4. Deploy from a branch 선택 → `main` / `/(root)` 선택 → Save.
5. 잠시 후 표시되는 `https://계정명.github.io/저장소명/` 주소로 접속합니다.

## AI 글쓰기
프로그램이 주제에 맞는 검증 중심 프롬프트를 만들고 복사합니다. `Gemini 열기`를 눌러 붙여 넣으세요. Gemini에서 최신 웹 검색을 수행하고 생성한 초안을 프로그램 편집기에 붙여 넣어 다듬습니다.
이 방식은 API 키와 서버가 필요 없는 반자동 방식입니다.

## 이미지
Wikimedia Commons 공개 API를 브라우저에서 검색합니다. 검색 결과의 썸네일을 확인하고 `본문에 삽입`을 누르면 편집기에 실제 이미지가 들어갑니다. 개별 파일의 라이선스와 출처 표시 조건은 반드시 원본 페이지에서 확인하세요.
네이버 블로그가 외부 이미지 붙여넣기를 허용하지 않으면 HTML 파일에서 이미지를 확인해 저장한 뒤 네이버 편집기에서 직접 업로드해야 합니다.

## 주의
- 이 프로그램은 주가·시세·재무 데이터를 자체 제공하지 않습니다.
- Gemini 검색 결과와 공시·시세 수치는 원문 출처에서 최종 확인하세요.
- 브라우저 로컬 파일 실행 시 클립보드 권한은 브라우저 정책에 따라 제한될 수 있습니다.
