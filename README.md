# FOCUS AI Prompt Studio v4.1

**모든 분야의 프롬프트를 전문가 수준으로 만드는 프롬프트 스튜디오.**
API 키가 필요 없습니다. 생성·진단·재설계가 100% 브라우저 안에서 동작합니다.

라이브: https://tcrew-vstock.github.io/focus-blog-assistant/

## v4.1에서 달라진 것
1. **AI API 의존 완전 제거** — Gemini API 키 입력·로컬 저장·호출 로직·[AI로 고도화] 버튼을 모두 없앴습니다. 이전 버전에 저장된 키는 업데이트할 때 자동 삭제됩니다. (타겟 AI 목록의 `Gemini`는 프롬프트 형식 최적화 대상일 뿐, API 호출이 아닙니다.)
2. **프롬프트 강도 2단** — `표준 실전형`과 `초정밀 전문가형(Deep Pro)`.
3. **작업별 전문가 블루프린트** — 40개 작업 유형마다 출력 스키마·엣지 케이스·품질 합격선을 정의하고 프롬프트 본문에 넣습니다.
4. **입력 의도 스마트 파싱** — 1~2줄 입력에서 목적 동작·키워드·수치·기술·대상·제약 표현·직접 지정한 표현을 뽑아 목표와 체크포인트에 반영합니다.
5. **모호성 처리 + 자가 검증 자동 포함** — 가정 선언 규칙, [확인 필요] 처리, 합격선 점검, 적대적 검토가 강도에 따라 자동으로 붙습니다.
6. **진단 정밀화** — 5요소 × 4~5개 세부 기준(총 22개)으로 어느 지시가 빠져서 품질이 떨어지는지 항목별로 지적하고, 재설계 시 원문의 수치·표현을 보존 목록으로 명시합니다.

## 프레임워크 & 타겟 AI
- 프레임워크: `CO-STAR`, `RTF`, `RISEN`, `단계별 추론(CoT)`, `예시 기반(Few-Shot)`, `크리에이티브·이미지`, `자동 추천`
- 타겟 AI: `범용`, `ChatGPT`, `Claude`, `Gemini`, `Perplexity`, `이미지 AI`
  - Claude → `<role> <thinking_process> <intent_signals> <context> <task> <assumptions> <output_schema> <edge_cases> <quality_rubric> <adversarial_review> <final_instruction>` XML 구조
  - ChatGPT → Markdown 섹션 + 작업 순서 + 출력 스키마 강제
  - Perplexity → 검색 질의 분해 + 출처 우선순위 + `[1]` 인라인 인용 + 미확인 정보 배제
  - 이미지 AI → 구조화된 영문 프롬프트 + 엔진별 파라미터(Midjourney `--ar/--v/--style raw/--stylize/--no`, Flux, DALL·E, SD 네거티브·설정) + 네거티브
  - 영상(Sora·Veo·Runway) → 3샷 타임코드·카메라 무빙·연속성·포맷까지 샷 리스트 + 샷별 프롬프트

## 유지된 기존 자산
- **시세 API 연동**: `https://focus-market-api.tcrewseadona.workers.dev`. 주식·경제 분야에서 조회한 값이 `[검증된 시장 데이터]` 블록으로 프롬프트에 자동 주입됩니다.
- **PWA**: `manifest.webmanifest`, `sw.js`, 로고 아이콘, 상단 `⤓ 앱 설치` 버튼
- **6종 AI 바로가기 칩**: ChatGPT, Gemini, Claude, Perplexity, Grok, 뤼튼
- **프리셋 14종 · 라이브러리** 저장·검색·필터·내보내기

## 배포
GitHub Pages (`main` 브랜치 루트) 자동 배포. 정적 파일만으로 동작하며 빌드 과정이 없습니다. 자산 버전 쿼리(`?v=4.1.0`)와 Service Worker 캐시 버전을 함께 올려 업데이트가 바로 반영됩니다.

## 데이터와 한계
- 생성·진단은 전부 브라우저에서 계산합니다. 입력한 내용은 서버로 가지 않습니다. AI API 키를 쓰지 않습니다.
- 저장(프롬프트·설정)은 `localStorage`에만 있으며 기기 간 동기화가 없습니다.
- 시세는 네이버 금융 공개 데이터를 워커가 중계한 값으로, 기준 시각과 장 상태가 함께 표시됩니다. 제공처에 없는 항목은 `—`로 비우며 추정값을 채우지 않습니다.
- 이미지 프롬프트는 영문 장면 설명을 권장합니다(한글도 가능하지만 모델에 따라 정확도가 떨어집니다).
- 엔진은 의도를 규칙 기반으로 해석합니다. 사용자가 적지 않은 고유 사실을 만들어 넣지는 않습니다.
