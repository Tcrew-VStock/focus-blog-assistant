# FOCUS AI Prompt Studio v4.0

**모든 분야의 프롬프트를 전문가 수준으로 만드는 프롬프트 스튜디오.**
API 키 없이 브라우저에서만 동작합니다. (Gemini 키를 넣으면 선택적으로 AI 고도화가 켜집니다.)

라이브: https://tcrew-vstock.github.io/focus-blog-assistant/

## 무엇이 달라졌나 (v3.0 → v4.0)
v3.0은 '경제·주식 블로그'에 특화된 콘텐츠 스튜디오였습니다. v4.0은 블로그 편중을 없애고, **8개 분야 × 6개 프레임워크 × 6개 타겟 AI** 조합으로 어떤 프롬프트든 설계하는 범용 엔진입니다.

### 1. 범용 프롬프트 빌더 (8개 분야)
| 분야 | 다루는 작업 |
|---|---|
| 💻 코딩·개발 | 앱·기능 구현, 디버깅, 리팩터링·코드리뷰, 바이브코딩, 구조·API 설계 |
| 💼 비즈니스·문서 | 기획서·제안서, 보고서, 이메일·공지, 원페이지, 회의록 |
| 📈 주식·경제·리서치 | 종목 딥다이브, 네이버 블로그, 장전·장마감 브리핑, 산업·테마, 경제 개념 해설 |
| 🎨 이미지·디자인·영상 | 실사·제품 사진, 일러스트, 로고, 영상 씬, 디자인 브리프 |
| 📚 학습·탐구보고서 | 수행평가, 탐구보고서(R&E), 시험대비, 외국어, 요약 노트 |
| 📱 마케팅·카피 | 크몽·스토어 상세페이지, SNS·카드뉴스, 쇼츠 대본, 광고 A/B, 캠페인 |
| ✍️ 글쓰기·콘텐츠 | 블로그, 에세이·칼럼, 뉴스레터, 스토리, 퇴고·첨삭 |
| ⚡ 만능·메타 | 한 줄 요청의 6단 확장, 리서치 설계, 의사결정, 업무 자동화, 학습 로드맵 |

### 2. 프레임워크 & 타겟 AI 최적화
- 프레임워크: `CO-STAR`, `RTF`, `RISEN`, `단계별 추론(CoT)`, `예시 기반(Few-Shot)`, `크리에이티브·이미지`, `자동 추천`
- 타겟 AI: `범용`, `ChatGPT`, `Claude(XML 태그)`, `Gemini`, `Perplexity(출처 인용)`, `이미지 AI(영문+파라미터)`
  - Claude 선택 시 `<role> <context> <objective> <instructions> <constraints> <output_format>` 구조로 출력
  - 이미지 AI 선택 시 영문 장면 프롬프트 + `--ar`, `--stylize`, `--no`(네거티브) 등 엔진별 파라미터 생성
- 세부 제어: 톤앤매너, 출력 형식(마크다운/표/코드/JSON/대본/체크리스트 등), 추론 깊이, 금지 사항, 출력 언어(한국어/영어/한영 병기), 대상·분량

### 3. 프롬프트 진단 & 업그레이드
기존 프롬프트를 붙여넣으면 **역할 정의 · 맥락·대상 · 구체적 지침 · 제약·금지사항 · 출력 형식** 5요소로 점수(0~100)를 매기고, 부족한 점과 보완 팁을 보여준 뒤 클릭 한 번으로 전문가급 프롬프트로 재설계합니다.

### 4. 변수 치환 & 라이브러리
- 비워 둔 입력은 `{{주제}}`, `{{대상}}` 같은 변수로 남고, [변수 채우기] 탭에서 값을 넣으면 프롬프트에 즉시 반영됩니다.
- 14개 프리셋(바이브코딩·종목 딥다이브·크몽 상세페이지·수행평가·Midjourney 제품 사진 등)
- 라이브러리: 저장·검색·도메인 필터·JSON/Markdown 내보내기

### 5. 실행 연결
원클릭 복사 + 6종 AI 바로가기 칩(ChatGPT, Gemini, Claude, Perplexity, Grok, 뤼튼).

## 유지된 기존 자산
- **시세 API 연동**: `https://focus-market-api.tcrewseadona.workers.dev` (quote / chart / valuation / financials / flows / news). 주식·경제 분야에서 조회한 값이 `[검증된 시장 데이터]` 블록으로 프롬프트에 자동 주입됩니다.
- **PWA**: `manifest.webmanifest`, `sw.js`, 로고 아이콘, 상단 `⤓ 앱 설치` 버튼
- **Gemini 연동**: 키가 있을 때만 [AI로 고도화] 버튼이 켜집니다. CORS를 막던 `Api-Revision` 헤더는 사용하지 않습니다.

## 구조

## 배포
GitHub Pages (`main` 브랜치 루트) 자동 배포. 정적 파일만으로 동작하며 빌드 과정이 없습니다.

## 데이터와 한계
- 생성·진단은 전부 브라우저에서 계산합니다. 입력한 내용은 서버로 가지 않습니다.
- 저장(프롬프트·설정·키)은 `localStorage`에만 있으며 기기 간 동기화가 없습니다.
- 시세는 네이버 금융 공개 데이터를 워커가 중계한 값으로, 기준 시각과 장 상태가 함께 표시됩니다. 제공처에 없는 항목은 `—`로 비우며 추정값을 채우지 않습니다.
- 이미지 프롬프트는 영문 장면 설명을 권장합니다(한글도 가능하지만 모델에 따라 정확도가 떨어집니다).
